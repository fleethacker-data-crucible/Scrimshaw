# Scrimshaw brand files

| File | Use |
| --- | --- |
| `scrimshaw-logo.png` | Full logo with wordmark, 1254 px master |
| `scrimshaw-logo-640.png` | Full logo for the README and docs |
| `scrimshaw-emblem.png` | The emblem alone (no wordmark), 1000 px square, for icons and small spaces |

The app uses two small copies made from the emblem: `src/assets/favicon.png` (64 px, browser tab) and
`src/assets/emblem.webp` (192 px, Projects dialog). The editor's top bar keeps the flat vector mark in
`src/editor/Logo.tsx` so it matches the other Edge-Ops apps at 25 px.

Colours drawn from the logo: navy `#031424`, ivory `#fbfaf2`, gold `#a8885c`.
